# Статус реализации

## Что есть в начальном каркасе

- Manifest для Foundry VTT 13.
- Регистрация типа персонажа «Жук».
- Модель данных персонажа: размер, четыре характеристики, основные ресурсы и заметки.
- Базовый лист персонажа на русском языке.
- Производные показатели: Нагрузка и Манёвренность.
- Простые Node.js-тесты расчёта двух производных показателей.
- Ручная сборка ZIP и публикация GitHub Release через GitHub Actions.

## Что пока не реализовано

- Автоматизация проверок и бросков.
- Урон, Впитывание, состояния и бой.
- Пути, Черты, Искусства, Тайны, Амулеты и экипировка как полноценные игровые элементы.
- Подготовка персонажа по шаблонам размеров.
- Компendium-паки и миграции данных.

## Важное замечание

Это технический каркас, а не законченная реализация правил. Перед автоматизацией каждой механики нужно сверить её с английским оригиналом и русским переводом, записать источник и проверить спорные места. Непроверенные правила не должны превращаться в автоматические игровые расчёты.
